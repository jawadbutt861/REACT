## 🔧 Technical Details

### Breakpoints Used
- `sm`: 640px (Mobile to Tablet)
- `md`: 768px (Tablet)
- `lg`: 1024px (Desktop)
- `xl`: 1280px (Large Desktop)

### Common Patterns
```css
/* Spacing */
px-2 sm:px-4              /* Responsive padding */
py-4 sm:py-6              /* Responsive padding */
gap-3 sm:gap-4            /* Responsive gap */

/* Layout */
flex-col lg:flex-row      /* Stack on mobile */
grid-cols-2 sm:grid-cols-3 lg:grid-cols-5  /* Responsive grid */
hidden lg:block           /* Hide on mobile */

/* Typography */
text-xs sm:text-sm        /* Responsive text */
text-xl sm:text-2xl lg:text-3xl  /* Responsive headings */

/* Sizing */
w-full lg:w-64            /* Full width on mobile */
h-64 sm:h-80 lg:h-100     /* Responsive height */
```
